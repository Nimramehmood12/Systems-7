# Day 6 - CNN Basics

Images are resized to a common shape and normalized to a stable numeric range.
Augmentation creates realistic variations and reduces overfitting. A
convolution applies local filters, producing feature maps; pooling reduces
spatial size while retaining strong signals. CNNs suit images because local
connectivity and weight sharing use far fewer parameters than a fully
connected network.

Run `python main.py`. Practice solutions are `q16_augmentation.py` and
`q17_cifar10_cnn.py`. TensorFlow is required.
