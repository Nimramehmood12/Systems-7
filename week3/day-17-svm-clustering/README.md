# Day 3 - SVM, Naive Bayes, and Clustering

SVMs find a maximum-margin boundary and can use kernels for nonlinear data.
Naive Bayes applies Bayes' rule with a conditional-independence assumption and
is often effective for high-dimensional text-like features. K-Means requires a
chosen `k`; an elbow curve and silhouette score help select it. Hierarchical
clustering gives a dendrogram, while DBSCAN finds dense regions and labels
noise without requiring a cluster count.

Run `python main.py`. Practice solutions are `q09_kmeans.py` and
`q10_nb_svm.py`.
