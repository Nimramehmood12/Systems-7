# Week 3: Model Evaluation, Advanced ML, Deep Learning, and CNNs

Week 3 builds from model evaluation through neural networks and computer vision.
Each day contains a short README, an executable practical task, and one file for
each code-practice question.

## Requirements

```bash
pip install -r week3/requirements.txt
```

Run a practical task from the repository root, for example:

```bash
python week3/day-15-model-evaluation/main.py
```

## Daily folders

- `day-15-model-evaluation`: metrics, cross-validation, confusion matrices, and ROC-AUC
- `day-16-tuning-model-comparison`: preprocessing, overfitting, and hyperparameter tuning
- `day-17-svm-clustering`: SVM, Naive Bayes, and clustering
- `day-18-pca-pipelines`: PCA, feature engineering, imbalance, leakage, and pipelines
- `day-19-neural-networks`: perceptrons and Keras tabular neural networks
- `day-20-cnn-basics`: image preprocessing and a CIFAR-10 CNN
- `day-21-image-classifier`: transfer learning and prediction visualization
