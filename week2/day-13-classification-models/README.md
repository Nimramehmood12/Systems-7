# Day 13 - Classification Models

This day compares four popular classification algorithms:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest

The script uses a reproducible train/test split, applies scaling for models that need it, and prints:

- Accuracy
- Classification report
- Feature importance for tree-based models

## Files

- `main.py` - classification model comparison

## Run

```bash
python week2/day-13-classification-models/main.py
```
