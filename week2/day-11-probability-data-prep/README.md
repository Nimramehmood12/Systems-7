# Day 11 - Probability and Data Preparation

This day covers:

- Basic probability with a simple coin-toss example
- Correlation between numeric variables
- Loading and inspecting a tabular dataset
- Handling missing and invalid values
- Separating features (`X`) and target (`y`)
- Reproducible train/validation/test splitting

## Files

- `sample_data.csv` - small local dataset used for practice
- `main.py` - data preparation workflow

## Run

```bash
python week2/day-11-probability-data-prep/main.py
```
