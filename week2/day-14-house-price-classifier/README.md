# Day 14 - House Price Predictor + Classifier

This day completes both practical tasks:

1. **House-price predictor (regression)**
   - Simple linear regression (`size_sqft -> price`)
   - Multiple linear regression (`size_sqft`, `bedrooms`, `age_years`, `distance_km` -> `price`)
   - Evaluation with `MAE` and `R2`
   - Predictions, intercept, and coefficients

2. **Basic classification model**
   - Random Forest classifier
   - Predicts whether a house is expensive (`is_expensive`)
   - Accuracy, classification report, and feature importance

## Files

- `main.py` - both practical tasks in one executable script
